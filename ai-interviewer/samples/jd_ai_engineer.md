# Senior AI Engineer — Applied GenAI Platform

We are building LLM-powered features (search, document Q&A, support agents) used by
200k business customers.

## What you'll do
- Design, ship and operate retrieval-augmented generation (RAG) systems in production.
- Build evaluation pipelines for LLM features: offline test sets, LLM-as-judge, online metrics.
- Build tool-using agents and keep them reliable, safe and affordable.
- Work with data engineering on document ingestion, chunking and embedding pipelines.
- Own latency and cost budgets for model calls.

## Must have
- 5+ years software/ML engineering, 2+ years shipping LLM features to production.
- Strong Python; solid SQL.
- Hands-on RAG: chunking, embeddings, hybrid retrieval, re-ranking, retrieval evaluation.
- Experience designing LLM evals and using them to make ship/no-ship decisions.
- Production ML/LLM system design: monitoring, fallbacks, caching, cost control.

## Nice to have
- Fine-tuning or distillation experience.
- Spark or other distributed data processing.
- Experience with agent frameworks and tool use.
